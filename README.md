# 🌸 Avatar Tu Tiên

Game avatar chibi phong cách tu tiên — giao lưu, trồng linh thảo, tán gẫu.

## Chơi ngay
- Chạy local: `npm install && npm start` rồi mở http://localhost:3001
- Deploy Render: Build `npm install`, Start `node server.js` (giống bản MMO)

## Tính năng
- 🏯 **Quảng trường Linh Giới**: đi lại, chat bong bóng, gặp gỡ
- 🌾 **Linh điền riêng**: 6 ô đất, gieo hạt → tưới linh tuyền → thu hoạch
- 🌱 3 loại cây: Linh Thảo, Tử Vân Hoa, Thiên Niên Linh Chi
- 🏪 Shop: mua hạt giống, mũ, bán nông sản lấy linh thạch
- 👘 Thay đồ: 6 màu áo, 3 loại mũ
- ✨ Tu vi lên cấp khi thu hoạch, lưu dữ liệu nhân vật
